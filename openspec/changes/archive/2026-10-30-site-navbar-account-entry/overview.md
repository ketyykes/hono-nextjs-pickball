# Overview: site-navbar-account-entry

## Scope

navbar 右側的帳號入口改為「永遠佔同一格寬度」：載入中與 auth 停用時放一個看不見的佔位元素，
`/api/session` 回應後連結不再左移（消除 webkit E2E 偶發不導覽與使用者誤點）。同時縮小窄螢幕的連結內距與容器間距，
讓帳號入口在手機寬度也能顯示，不再只能手動輸入 `/login`。

**Size**: small — 影響 2 個 capability（site-navbar、auth 只改說明與一條 Scenario），16 個 tasks，無新相依、無架構變更（tasks 數略超過 small 門檻，但改動集中在 3 個元件檔與 3 個測試檔）。
**Frontend involved**: yes — navbar 版面與帳號入口的視覺狀態。
**DB schema touched**: no — 後端零變更。
**Data migration**: no — 無資料。
**Cross-component flow**: no — 只是單一元件依 session 狀態渲染，無新的非同步流程。

---

## What Changes

- `AccountEntry`：loading／disabled 由「不渲染」改為「隱形佔位（同寬）」。
- `AccountEntry`：移除 `hidden sm:inline-flex`，所有寬度顯示。
- `NAV_ITEM_BASE`：`< sm` 內距各降一階（`px-2`→`px-1.5`、`< 375` 的 `px-1.5`→`px-1`）。
- `SiteNavbar` 內層容器：`< sm` 的 `gap-3` → `gap-1`。
- `auth` 登入頁說明：窄螢幕登出不再只能在 `/login`。

Before / after 對照：

```
=== Before ===
loading/disabled : [logo]        [首頁 完整體驗 計分板 測驗 對戰分配]
ready (enabled)  : [logo]   [首頁 完整體驗 計分板 測驗 對戰分配]  [->]
                             ^ 整排左移 = 位移
< 640px          : 入口 hidden，只能手打 /login

=== After ===
loading/disabled : [logo]   [首頁 完整體驗 計分板 測驗 對戰分配]  [  ]
ready (enabled)  : [logo]   [首頁 完整體驗 計分板 測驗 對戰分配]  [->]
                             ^ 位置不變                        ^ 同寬
< 640px          : 入口可見（內距與 gap 縮小讓位）
```
