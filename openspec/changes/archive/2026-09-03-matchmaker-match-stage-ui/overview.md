# matchmaker-match-stage-ui（M5：對戰畫面）

## Scope

把「對戰分配機」第一次變成看得見的東西：新增 `/matchmaker` 對戰頁，用滿版方型色塊呈現每個
場地的對戰（單打兩格左右、雙打四格 2x2），旁邊列出休息名單，下方可直接手動輸入比分並送出。
同時把 matchmaker 掛進全站 navbar——這是 M1 明文遞延到「對戰畫面完成後」才處理的導覽整合。

**規模判定：large。** 影響 2 個 capability（新增 `match-stage`、修改 `site-navbar`），但
tasks 超過 20 項（15 個 Requirement——match-stage 13 + site-navbar 2、51 個 Scenario、
三層測試），依規模表「tasks > 20 即為 large」判定。

條件式區塊判定：

| 條件 | 判定 | 理由 |
|---|---|---|
| 前端需求 → UI Mockups | ✅ 有 | `match-stage` 的 13 個 Requirement 幾乎全在描述版面、視覺狀態與互動 |
| 資料庫結構 → Data Model | ❌ 無 | 本版資料層只有瀏覽器 LocalStorage，且 schema 由 M1／M4 定義，本 change 只讀不寫結構 |
| 資料遷移 → Data Migration | ❌ 無 | 不搬移、不轉換任何既有資料；新路由對既有 `matchmaker:roster:v1` 為唯讀 |
| 跨元件流程 → Sequence Diagram | ✅ 有 | 「送出比分」是順序敏感的多步互動（驗證 → 評分 → 歷史 → 持久化 → 重繪），且本 change 與 M4 的職責邊界正好切在這條鏈上，畫出來才說得清誰做哪一段 |

## What Changes

- 新增 `/matchmaker` 對戰頁與 `app/matchmaker/layout.tsx` 區段外框（含「對戰／參賽者」區段導覽）
- 本輪設定控制項：對戰方式（預設單打）、場地數（1～8，預設 1）、目標分數（11／15／21，預設 11）
- 滿版色塊舞台：單打 2 格左右、雙打 4 格 2x2（上排第一隊、下排第二隊），每格顯示姓名、性別、
  強度分數，背景為該員雙色漸層
- 休息名單輔助區（姓名、顏色標記、累計休息次數），桌面在右側、手機移到下方
- 空白球場狀態，依名單狀態分流為「建立第一輪」或「加入參賽者」
- 手動輸入比分與送出，驗證錯誤以繁體中文顯示在該場次
- 完成場次以半透明低飽和呈現，顯示最終比分、勝方與完成時間
- 強度觸頂／觸底時於色塊標示「已達上限」／「已達下限」
- RWD 三斷點（桌面／平板／手機）
- `SiteNavbar` 新增第 5 條連結「對戰分配」→ `/matchmaker`

前後對照（純文字，不含 UI 細節）：

```
=== Before ===

  全站 navbar : 首頁 | 完整體驗 | 計分板 | 測驗
  matchmaker  : /matchmaker/players  只能維護名單（未掛進 navbar）
                /matchmaker          404
  分配引擎    : lib/matchmaker/allocation.ts  已完成，無人呼叫
  回合狀態    : M4 已提供，無畫面消費

=== After ===

  全站 navbar : 首頁 | 完整體驗 | 計分板 | 測驗 | 對戰分配
  matchmaker  : /matchmaker          對戰頁（場次舞台）  ← 新增
                /matchmaker/players  參賽者名單（不變）
                兩頁以區段導覽互通
  分配引擎    : 經由 M4 的 pipeline 被對戰頁觸發
  回合狀態    : 產生 / 重排 / 送出比分皆由對戰頁的操作入口驅動
```

## Task Tree

tasks.md 的分群與相依。§2～§6 是純函式群，彼此獨立、可依序快速推進；§7 之後的元件群依賴
它們，§11 的頁面組裝依賴全部元件。

```
§1 環境與相依確認（Step 0 的延伸: 確認 M4 / M3 的實際匯出）
 │
 ├─ §2 section-nav.ts          （區段導覽的分頁與 active）
 ├─ §3 round-settings.ts       （預設值與場地數夾值）
 ├─ §4 stage-layout.ts         （單打 2 格 / 雙打 2x2）

      │
      ├─ §7 RoundControls      （設定 + 產生 + 重設）  depends §3
      ├─ §8 CourtCard          （色塊 + 比分 + 完成）  depends §4 §5 §6
      ├─ §9 RestingPanel       （休息名單 + 兩種空狀態）
      └─ §10 SiteNavbar        （第 5 條連結）         depends §2 無
            │
            └─ §11 頁面組裝與 E2E                      depends §2-§10

                       │
                       └─ §12 收尾驗證（lint / tsc / unit / e2e / validate）
```
