# Overview: local-fallback-export-reminder

## Scope

把本機備援期間常駐提示的文案改一句：除了「修改只存在這台裝置」，再提醒使用者重新整理前先到「資料」頁匯出 JSON 備份，連線後再選擇備份檔匯入雲端。因為重新整理並連上雲端後，本機資料就沒有任何入口可匯出了。

**Size**: small — 影響 1 個 capability、tasks ≤8、無新依賴、無架構變更
**Frontend involved**: yes — 提示是使用者可見的 UI 文字
**DB schema touched**: no — 不動資料庫
**Data migration**: no — 不搬移資料
**Cross-component flow**: no — 單一常數字面值，無跨元件時序

---

## What Changes

- `LOCAL_FALLBACK_NOTICE` 改為含備份提醒的新文案（63 字，原 32 字）。
- 測試的字面值斷言、一處文件（`nextjs-pickball/CLAUDE.md`）與主 spec 舊文案同步更新；元件與樣式不改，不加連結或按鈕。

```
=== Before ===
提示：目前連不上雲端，修改只會存在這台裝置；重新整理頁面可再次連線雲端
      → 使用者重新整理，連上雲端後本機資料無入口可匯出

=== After ===
提示：目前連不上雲端，修改只會存在這台裝置。重新整理會再次連線雲端，
      請先到「資料」頁匯出 JSON 備份，連線後再選擇備份檔匯入雲端
      → 使用者先匯出（備援期間匯出的是本機資料），連線後再匯入雲端
```
